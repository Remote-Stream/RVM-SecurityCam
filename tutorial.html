شروع کار با RemoteVM Monitor

نکته: این سیستم بر پایه VDO.Ninja (RemoteVM) کار می‌کند و نیازی به نصب نرم‌افزار ندارد.
1

افزودن دوربین جدید

روی دکمه "افزودن دوربین" کلیک کنید و اطلاعات زیر را وارد نمایید:

  • نام دوربین (برای شناسایی)
  • Stream ID (فقط حروف انگلیسی و اعداد)
  • رمز عبور (اختیاری برای امنیت بیشتر)
2

دریافت لینک‌ها

پس از وارد کردن اطلاعات، دو لینک برای شما ساخته می‌شود:

Push URL: برای ارسال تصویر از دوربین View URL: برای مشاهده تصویر دوربین
3

فعال‌سازی دوربین

برای مشاهده تصویر دوربین، روی دکمه "فعال‌سازی" در کارت دوربین کلیک کنید.

امکانات کلیدی

نمایش چندگانه

قابلیت نمایش 1، 4، 9 یا 16 دوربین به صورت همزمان در یک صفحه

حالت تمام صفحه

مشاهده هر دوربین در حالت تمام صفحه با یک کلیک

امنیت بالا

پشتیبانی از رمز عبور برای هر دوربین جهت جلوگیری از دسترسی غیرمجاز

LAN Only

امکان محدود کردن دسترسی فقط به شبکه داخلی

اتصال خودکار

اتصال مجدد خودکار در صورت قطع ارتباط

ذخیره‌سازی

ذخیره تنظیمات و لیست دوربین‌ها در مرورگر

پارامترهای پیشرفته

پارامترهای رایج

پارامتر توضیحات کاربرد
&autostart شروع خودکار استریم فقط در Push URL
&retry تلاش مجدد در صورت قطعی فقط در Push URL
&webcam استفاده از وبکم فقط در Push URL
&cleanoutput حذف UI اضافی View URL
&muted بی‌صدا به صورت پیش‌فرض View URL
&lanonly فقط شبکه داخلی هر دو URL
&bitrate=5000 کیفیت بالا View URL
&framerate=30 30 فریم بر ثانیه View URL
توجه: استفاده از پارامترهای اشتباه ممکن است باعث عدم کارکرد صحیح دوربین شود.

نکات امنیتی

استفاده از رمز عبور

برای جلوگیری از دسترسی غیرمجاز به دوربین‌های خود، حتماً از رمز عبور استفاده کنید. رمز عبور باید:

  • حداقل 8 کاراکتر داشته باشد
  • ترکیبی از حروف و اعداد باشد
  • برای هر دوربین منحصر به فرد باشد

استفاده از LAN Only

اگر دوربین‌های شما فقط در شبکه داخلی استفاده می‌شوند، گزینه LAN Only را فعال کنید تا از دسترسی اینترنتی جلوگیری شود.

Stream ID امن

از Stream ID های قابل حدس مانند "camera1" یا "test" استفاده نکنید. از ترکیب‌های پیچیده و تصادفی استفاده کنید.

مثال خوب: xK9mP2nQ7 مثال بد: camera1
هشدار امنیتی: هرگز لینک‌های Push خود را در مکان‌های عمومی به اشتراک نگذارید.

سوالات متداول

چرا تصویر دوربین نمایش داده نمی‌شود؟

ممکن است به دلایل زیر باشد:
• دوربین فعال نشده است (روی دکمه فعال‌سازی کلیک کنید)
• Stream ID در فرستنده و گیرنده یکسان نیست
• مرورگر اجازه دسترسی به دوربین را نداده است
• اتصال اینترنت قطع یا ضعیف است

آیا می‌توانم بیش از 16 دوربین اضافه کنم؟

بله، محدودیتی در تعداد دوربین‌های قابل اضافه کردن وجود ندارد. اما نمایش همزمان حداکثر 16 دوربین پشتیبانی می‌شود. می‌توانید دوربین‌های بیشتری اضافه کنید و آنها را به صورت انتخابی فعال/غیرفعال کنید.

چگونه می‌توانم ویدیو را ضبط کنم؟

در حال حاضر قابلیت ضبط مستقیم در این نسخه وجود ندارد. برای ضبط می‌توانید از نرم‌افزارهای ضبط صفحه مانند OBS Studio یا ابزارهای مشابه استفاده کنید.

آیا اطلاعات من ذخیره می‌شود؟

تمام اطلاعات فقط در مرورگر شما (LocalStorage) ذخیره می‌شود و به هیچ سرور خارجی ارسال نمی‌گردد. ارتباط ویدیو نیز به صورت P2P و رمزنگاری شده است.

چه مرورگرهایی پشتیبانی می‌شوند؟

مرورگرهای مدرن زیر پشتیبانی می‌شوند:
• Google Chrome (نسخه 80+)
• Mozilla Firefox (نسخه 75+)
• Microsoft Edge (نسخه 80+)
• Safari (نسخه 14+)

برای بهترین عملکرد، استفاده از Chrome توصیه می‌شود.
